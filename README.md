# PetPals

A multi-page pet shop website, built for a client.

**Live:** [p3tpals.netlify.app](https://p3tpals.netlify.app)

## Features

- Home page with a video hero
- Browsable pets listing and individual product pages
- Shopping cart
- Blog, About and Contact pages
- Client-side routing between pages

## Stack

React 18 · React Router · Vite · deployed on Netlify

## Run locally

```bash
npm install
npm run dev
```
