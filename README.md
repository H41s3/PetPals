# PetPals

A front-end website design for a pet shop, built for a client.

**Live:** [p3tpals.netlify.app](https://p3tpals.netlify.app)

> UI only: this is a static front-end. There is no backend, checkout or real cart logic.

## Pages

- Home with a video hero
- Pets listing and individual product pages
- Cart page
- Blog, About and Contact pages
- Client-side routing between pages

## Stack

React 18 · React Router · Vite · deployed on Netlify

## Run locally

```bash
npm install
npm run dev
```
